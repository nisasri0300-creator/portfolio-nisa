Production Line Balancing & Ergonomic Layout

LUNAE · Production Improvement Case | Applying takt time, cycle time, workstation balancing, bottleneck analysis, and ergonomic flow.

01 · Project Context

LUNAE is a fashion product project centered on a modular kimono-style shirt. This case treats production as a measurable system: material is transformed through a sequence of operations, and each operation must support the required production pace while maintaining quality and a workable operator environment[cite: 13].

02 · Objective

Develop a practical production-line improvement framework for LUNAE by connecting demand with takt time, actual cycle time, workstation allocation, bottleneck identification, line balancing, and ergonomic layout. The purpose is to improve flow and usable capacity before assuming that additional labor, machines, or floor space are required[cite: 13].

03 · Reference Methodology

The methodology is informed by iFactory's manufacturing guidance on takt time, cycle time, line balancing, workstation analysis, and production monitoring. iFactory describes takt time as the production pace required by customer demand and distinguishes it from cycle time, the actual time required by a process or workstation[cite: 13].

Primary reference: iFactory — Production Line Balancing, Takt Time & Workstation.

04 · Owner Perspective

For an owner, production efficiency is not simply about keeping operators busy. The objective is to create a production system whose capacity can be understood, measured, and improved against actual demand[cite: 13].

  • • What output is required from the line?[cite: 13]
  • • What production pace is required to satisfy that demand?[cite: 13]
  • • Which workstation is actually limiting flow?[cite: 13]
  • • Where is work accumulating or waiting?[cite: 13]
  • • Can work content be redistributed between stations?[cite: 13]
  • • How much capacity is lost through imbalance or unnecessary movement?[cite: 13]
  • • Can the workstation be redesigned to improve both productivity and operator comfort?[cite: 13]

05 · Production Flow

MATERIAL PREPARATION → CUTTING → SEWING → FINISHING → QUALITY CHECK → PACKING

For LUNAE, the sewing process can be decomposed into individual work elements such as component preparation, joining, sleeve-related operations, detail finishing, and inspection. The final sequence should follow the approved production method and actual work instructions[cite: 13].

06 · Takt Time vs. Cycle Time

Concept Formula / Meaning Use in LUNAE
Takt Time Available production time ÷ required customer output Sets the required production pace.
Cycle Time Actual time required to complete one unit at a process/workstation Measures the real operating pace.
Takt Adherence Whether actual cycles stay at or below the required pace Shows whether the station can consistently keep up.

Takt time is a target pace derived from demand; it is not the same as actual cycle time. A workstation whose cycle time repeatedly exceeds takt creates a capacity problem that should be investigated through work-content analysis and line balancing[cite: 13].

07 · Line Balancing

Line balancing distributes feasible work elements across workstations so that workloads are as balanced as practical relative to the required production pace[cite: 13].

Metric Basic Logic Decision
Work Content Sum of task times required for one unit Understand total labor content.
Workstation Load Task time assigned to a workstation Compare workload between stations.
Line Efficiency Total work content ÷ (workstations × cycle-time target) Evaluate balance of assigned capacity.
Balance Loss 1 − line efficiency Quantify capacity lost through imbalance.

08 · Bottleneck Analysis

The visible queue is not automatically the root bottleneck. iFactory's simulation material highlights that queues can be downstream effects and that constraints can shift after upstream improvements[cite: 13].

  • • Measure actual cycle time by operation and across multiple observations[cite: 13].
  • • Compare each workstation against the required takt[cite: 13].
  • • Observe WIP accumulation and waiting before and after stations[cite: 13].
  • • Separate planned work from downtime, material shortage, and quality rework[cite: 13].
  • • Check whether the constraint changes when work is redistributed[cite: 13].
  • • Prioritize improvements that increase total line throughput, not only local speed[cite: 13].

09 · Ergonomic Layout

Ergonomic layout is treated as part of production-system design to minimize unnecessary reaching, walking, awkward posture, and material-handling movement[cite: 13].

  • • Place frequently used materials within an efficient reach zone[cite: 13].
  • • Arrange machines and worktables according to process sequence[cite: 13].
  • • Reduce unnecessary walking between consecutive operations[cite: 13].
  • • Separate incoming material, work-in-process, and completed work[cite: 13].
  • • Maintain clear material flow and avoid crossing paths where practical[cite: 13].
  • • Set suitable working height and seating conditions for the task[cite: 13].

12 · Improvement Roadmap

  • 01 — Map the actual LUNAE production sequence[cite: 13].
  • 02 — Break the process into measurable work elements[cite: 13].
  • 03 — Collect cycle-time observations across representative conditions[cite: 13].
  • 04 — Calculate takt time from actual demand and time[cite: 13].
  • 05 — Compare cycle time and takt by workstation[cite: 13].
  • 06 — Identify the true constraint using flow, WIP, and capacity evidence[cite: 13].
  • 07 — Rebalance feasible work content between workstations[cite: 13].

13 · Definition of Success

The target is a production line whose capacity is measurable and aligned with demand: workstations operate at an appropriate pace, bottlenecks are visible, work is distributed more evenly, material movement is controlled, and the operator environment supports consistent work[cite: 13].
